### 👨‍💻 Sobre Mim

Venho de uma trajetória sólida em sustentação e estabilidade de infraestrutura corporativa de TI, momento em que decidi estruturar uma transição consistente e orientada à prática para as áreas de **Ciência de Dados, Engenharia de Machine Learning e Inteligência Artificial**.

Minha atuação é focada na entrega de ponta a ponta: desde a higienização e normalização de dados semiestruturados (ETL) até a modelagem preditiva, orquestração de agentes inteligentes com arquitetura **RAG** e desenvolvimento de aplicações web resilientes.

* 🏆 **Reconhecimento Nacional:** Integrante da equipe classificada no **Top 20 Melhores Equipes do Brasil** no **Hackathon ONE II** (promovido por Oracle, Alura Latam e No Country), desenvolvendo solução de Machine Learning para análise de sentimentos integrada via API REST.
* 🚀 **Aplicações em Produção:** Desenvolvedor do **EduAgent IA**, assistente virtual documental com LangChain, FAISS e LLMs com deploy público ativo no Streamlit.
* ☁️ **Fundamentação em Nuvem:** Certificado **Oracle Cloud Infrastructure (OCI) 2025 Foundations Associate**.
* 🎓 **Formação Acadêmica:** Graduando em Inteligência Artificial (UNIFOR), Pós-Graduando em Informática na Educação (IFSULDEMINAS) e Bacharel em Sistemas de Informação (Uni7).

### 🌟 Principais Projetos em Destaque

#### 🤖 [EduAgent IA — Assistente Virtual com RAG](https://github.com/dfarneym/eduagent-ia)
> **Stack:** Python | LangChain | FAISS | LLMs | Streamlit Cloud  
> **Aplicação Ativa:** [eduagent-ia.streamlit.app](https://eduagent-ia-dk7w4kiyu2zetyb5ixkstg.streamlit.app/)  
> Assistente inteligente voltado para mitigar alucinações em consultas sobre bases documentais densas. Utiliza arquitetura RAG (*Retrieval-Augmented Generation*) com particionamento semântico, busca por similaridade vetorial via FAISS e interface ágil em Streamlit.

#### 🏅 [Hackathon Oracle ONE II — Análise de Sentimentos em Escala](https://github.com/dfarneym)
> **Reconhecimento:** Top 20 Melhores Equipes do Brasil (Oracle / Alura)  
> **Stack:** Python | Machine Learning (NLP/Classificação) | APIs REST | ETL | Scrum/Lean  
> Atuação no time de Data Science em ciclo ágil de 5 semanas. Desenvolvimento do pipeline completo de dados (ETL, EDA, vetorização e treinamento) e disponibilização do modelo preditivo via API REST para integração direta com a equipe de Back-End.

#### 📱 [Sistema de Avaliação de Atendimento ao Cidadão (PWA Offline-First)](https://github.com/dfarneym/atendimeto_ao_cidadao)
> **Stack:** React 18 | TypeScript | IndexedDB (idb) | Service Workers | Vite | TailwindCSS  
> Aplicação progressiva resiliente desenvolvida para totens e tablets em postos públicos de atendimento. Opera de forma 100% autônoma sem internet (*Offline-First*), com cache de assets e persistência transacional de feedbacks no IndexedDB, além de dashboard administrativo com PIN para métricas (KPIs).

#### 🧹 [Precificação Inteligente: Transformação e Limpeza de Dados](https://github.com/dfarneym/precificacao_inteligente)
> **Stack:** Python | Pandas | NumPy | Regex | JSON Aninhado | Datetime  
> Pipeline de engenharia de dados voltado para dados semiestruturados do setor imobiliário. Normalização de JSONs aninhados (`pd.json_normalize`), desacoplamento de listas com `explode()`, padronização monetária com Expressões Regulares e análise de sazonalidade temporal.

#### 📊 [TelecomX: Predição e Prevenção de Churn](https://github.com/dfarneym/TelecomX_BR)
> **Stack:** Python | Pandas | Scikit-Learn | SMOTE | Machine Learning  
> Identificação de variáveis determinantes para cancelamento de clientes em telecomunicações. Aplicação de SMOTE para balanceamento amostral severo e treinamento de classificadores focados em métricas de negócio (Recall e F1-Score na classe de risco).
